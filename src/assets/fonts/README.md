# Fonts

- `Fredoka.ttf` — SIL OFL 1.1 (see OFL-Fredoka.txt). Rounded display face used as the UI font;
  it is the closest openly-licensed match to the Among Us UI face (community-attributed as
  the commercial font 'Roostt', which we do not ship).
- `custom/ui.ttf` — OPTIONAL and git-ignored. If you own a licence for the real game UI font,
  drop it here; `styles.css` prefers it over Fredoka automatically.
