## Engine risks found while cross-checking (not fixed: not my files)
1. `src/engine/suspicion.ts` `hardFacts`: `sawVent` ⇒ certain impostor, `sawKill` ⇒ certain killer. Wrong when the lobby has
   **Engineers** (crew vent) or **Shapeshifters** (killer wears someone else's look). The domain model has no "roles enabled"
   field; suggest `LobbySettings.roles?: { engineer?: boolean; shapeshifter?: boolean; phantom?: boolean; viper?: boolean }` and a
   downgrade to near-hard when on (rules in lieChecks `saw_vent` / `saw_kill`).
2. Kill window starts at `t − killWindow.defaultSec`; it can be tightened with `roundStart + killCooldownSec` (round 0: +10 s)
   because the cooldown resets at every meeting end (lieChecks `cooldown_window`).
3. A `visualConfirmed` `sawTask` should also require that the task is visual **on this map** (MIRA asteroids/shields are not).
4. `docs/DEDUCTION_ENGINE.md` hard-constraint table lists asteroids/shields/garbage as visual generally — Skeld only.
